# 🎹 Rickkey Studio — Premium Custom Keyboard Store

Welcome to **Rickkey Studio**, a premium, high-end e-commerce storefront showcasing elite custom mechanical keyboards and artisan accessories. This project delivers a luxury, high-performance shopping experience featuring interactive image galleries, smooth sliders, and a dynamic live-updating cart system.

越南 Tên cửa hàng: **Rickkey Studio**  
📸 **Instagram:** [@rickkey2110](https://www.instagram.com/rickkey2110)

---

## ✨ Features

- **Luxury Light Theme:** Clean Apple-inspired aesthetics with a vibrant white and sky-blue palette.
- **Dynamic Product Showcase:** Displays a curated lineup of premium keyboards (`Lucky65 V3 Pro`, `Rainy75`, `MonsGeek M1W`, `Weikav RO75`, `Akko 5075B Plus`, and `GMK67`).
- **Smooth Auto-Sliders:** Every product card features its own independent automatic image loop gallery.
- **Deep-Dive Product Modals:** Clicking any card opens a beautifully structured overlay featuring high-definition thumbnail navigation, extensive write-ups, and complete spec sheets.
- **Advanced Shopping Cart:** Dynamic quantity modifiers with a built-in real-time state manager and an instant item removal (`🗑️ Xóa`) utility.

## 🛠️ Built With

- **HTML5** - Semantic layout structure.

## 🚀 Quick Start / Local Deployment

To run this storefront locally on your desktop machine:

1. Clone or download this repository to your computer.
2. Ensure that all the high-resolution product image files (`.jpg`) are placed **directly inside the same root directory** alongside `index.html`.
3. Open `index.html` using any modern web browser (Google Chrome, Microsoft Edge, Cốc Cốc, or Safari).
